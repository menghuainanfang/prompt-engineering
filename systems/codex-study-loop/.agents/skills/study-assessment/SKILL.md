# 掌握度体检

开始涉及学习档案的工作时，读取 [档案协议](../study-notes/references/archive.md)。沿用已定位的档案与当前保存模式；仅 realtime 或本轮归档时执行先写后答。
读取 [评估规则](references/assessment.md)。先确定要评什么以及为了什么；已有目标不再询问。
复用课程地图和既有证据，列出知识点、目标水平和关键桥点。自评只作抽测线索，标“会”的关键点仍需要实测。
一次一题：先标准应用，再用改变条件或追问理由区分会套与理解。不给题前提示暗示解法；提供提示后记录支持程度，不计为独立完成。
回答后只解释判定需要的差异，不把整场体检变成长课。用户请求讲解时可切到教学，保存未测项。
生成报告或复检时读取 [报告结构](references/report.md)。报告记录目标、题目、用户回答摘要、提示、当前水平与证据、所需水平、判定与补缺动作。未测=未知，不能假定达标或零基础。
复检更新同一报告并保留历次结果，重点检查原薄弱点；目标改变时重算要求。
评估结果可写回已有课程地图和相关知识笔记，只更新受证据支持的部分。

### 核心定义：数列极限的 ε-N 语言

- **ε-N 定义**：设 {aₙ} 为数列，a 为定数。若 ∀ε>0，∃N∈ℕ，当 n>N 时恒有 |aₙ−a|<ε，则称 {aₙ} 收敛于 a，记作 lim aₙ = a。
  - 核心思想：无论 ε 多小，总能在数列的"后面"找到一项，之后所有项都在 a 的 ε 邻域内
  - 几何意义：存在 N，使 a_{N+1}, a_{N+2}, ... 全部落入 (a−ε, a+ε)

### 基本性质

- **有界性**：若数列 {aₙ} 收敛，则 {aₙ} 有界。即 ∃M>0，对一切 n 有 |aₙ|≤M。
  - 注意：有界不一定收敛，但收敛一定有界

- **唯一性**：若数列 {aₙ} 收敛，则其极限唯一。
  - 证明思路：假设有两个不同极限 a≠b，取 ε=|a−b|/2，导出矛盾

- **保序性**（保号性）：若 lim aₙ = a > 0，则存在 N，当 n>N 时 aₙ > a/2 > 0。
  - 推论：若从某项起 aₙ ≥ bₙ 且两数列均收敛，则 lim aₙ ≥ lim bₙ

- {补充：四则运算法则}
  - 若 lim aₙ = a，lim bₙ = b，则 lim(aₙ±bₙ) = a±b，lim(aₙ·bₙ) = ab，lim(aₙ/bₙ) = a/b (b≠0)

- {补充：迫敛性（夹逼定理）}
  - 若 aₙ ≤ bₙ ≤ cₙ 且 lim aₙ = lim cₙ = l，则 lim bₙ = l

### 核心定理

- **单调有界收敛定理**：单调递增有上界的数列必收敛，极限即为上确界。
  - 使用条件：①单调（递增或递减）②有界（有上界或下界）
  - 意义：是判断数列收敛但不事先知道极限值的重要工具——只需判断单调性和有界性
  - 应用：自然底数 e 的构造——aₙ = (1+1/n)ⁿ 单调递增有上界

- **对比概念** → [[无穷大量]]（极限不存在但有明确趋势）

### M2：定理陈述

- **核心内容**：DCT 的两个独立条件——(C1) $f_n\to f$ a.e. (C2) $\exists$ 可积 $g$ 使 $|f_n|\leq g$ a.e.。
  结论：$\lim\int f_n = \int \lim f_n$，且更强地 $\int|f_n-f|\to 0$（$L^1$ 收敛）。
  - **几乎处处收敛允许零测集上的坏行为**：你的诊断回答完全正确——$f_n$ 仅在 $x=0$ 处发散，$\{0\}$ 零测，所以 $f_n\to 0$ a.e.

### M3：证明拆解

- **核心内容**：利用 $g\pm f_n\geq 0$ 构造非负辅助列 → 分别用 Fatou → 得到 $\limsup\int f_n\leq\int f\leq\liminf\int f_n$ → 配合 $\liminf\leq\limsup$ 逼出等号。

## 四、完整串联（讲义版）

> 以你标记的要点为节点、其他知识为线索，串联整个板块。通读一遍即可重建本节全貌。

### 起点：数列极限的 ε-N 定义

设 {aₙ} 为数列，a 为定数。若 ∀ε>0，∃N∈ℕ，当 n>N 时恒有 |aₙ−a|<ε，则称 {aₙ} 收敛于 a，记作 lim aₙ = a。

这一定义用两个量词把「无限接近」变成了一句严格的话：先给定任意小的距离 ε，再要求数列从某一项起全部落在 (a−ε, a+ε) 内。「接近」没有度量，ε 给了度量；「最终」没有终点，N 给了终点。本节后面所有性质都是从这个定义推出来的——这也是为什么极限的性质全都绕不开 ε-N。

### 线索：ε-N 语言的基本功

读 ε-N 定义要先读对量词顺序：先 ∀ε 后 ∃N，N 可以依赖 ε。典型练习：用定义证明 lim 1/n = 0——任给 ε>0，取 N = ⌈1/ε⌉，则 n>N 时 |1/n − 0| = 1/n < 1/N ≤ ε。

### 节点：有界性

- **定义**：若数列 {aₙ} 收敛，则 ∃M>0 使对一切 n 有 |aₙ|≤M。
- **推导**：取 ε=1，由定义 ∃N，n>N 时 |aₙ−a|<1，即 |aₙ|<|a|+1；前 N 项是有限个数，取 M = max{|a₁|,…,|a_N|, |a|+1} 即可。
- **关键性质**：有界是收敛的必要条件——收敛一定有界，有界不一定收敛（如 (−1)ⁿ）。逆否命题常用来证发散。
- **例子**：aₙ = sin n 有界（|sin n|≤1）但极限不存在。
- **常见误区**：把「有界 + 单调」拆开用——单独有界或单独单调都不保证收敛，两者合起来才够（见单调有界定理）。
- **一句话直觉**：收敛的数列不可能"跑到无穷远"，所以必然被圈在有限范围内。

### 节点：唯一性

- **定义**：若数列 {aₙ} 收敛，则其极限唯一。
- **推导**：假设有两个极限 a≠b，取 ε=|a−b|/2。由定义 ∃N₁ 使 n>N₁ 时 |aₙ−a|<ε，∃N₂ 使 n>N₂ 时 |aₙ−b|<ε。取 n>max{N₁,N₂}，则 |a−b| ≤ |a−aₙ|+|aₙ−b| < 2ε = |a−b|，矛盾。
- **关键性质**：极限是良定义的——「lim aₙ」这个记号指代的对象是确定的，这让后续所有极限运算有了合法性基础。
- **例子**：aₙ = (−1)ⁿ/n 不可能同时收敛到 0 和 0.1——唯一性保证了这种情况不会发生。
- **常见误区**：唯一性说的是"极限值唯一"，不是说"数列只有一种收敛方式"——同一个极限可以由完全不同的数列达到。
- **一句话直觉**：一个数列不可能同时"无限接近"两个不同的数。

### 线索：从"描述极限"到"计算极限"——四则运算

若 lim aₙ = a，lim bₙ = b，则 lim(aₙ±bₙ) = a±b，lim(aₙ·bₙ) = ab，lim(aₙ/bₙ) = a/b（b≠0）。这条法则本身不是本节重点（证明略），但它和下面的保序性配合，是处理具体数列的基本工具。

### 节点：保序性（保号性）

- **定义**：若 lim aₙ = a > 0，则 ∃N，当 n>N 时 aₙ > a/2 > 0。
- **推导**：取 ε = a/2，由定义 n>N 时 |aₙ−a| < a/2，即 a/2 < aₙ < 3a/2。
- **关键性质**：推论——若从某项起 aₙ ≥ bₙ 且两数列均收敛，则 lim aₙ ≥ lim bₙ（注意：严格不等号取极限后可能退化，如 1/n > 0 但极限等于 0）。
- **例子**：aₙ = 1 + 1/n > 0 对一切 n 成立，lim aₙ = 1 > 0——与保号性一致；反例警示：aₙ = 1/n > 0 但 lim aₙ = 0，说明"每项为正"推不出"极限为正"，只能推出"极限非负"。
- **常见误区**：把严格不等号带过极限——aₙ > bₙ 只保证 lim aₙ ≥ lim bₙ，等号可能发生。
- **一句话直觉**：极限值把数列的"最终符号倾向"固定下来——最终为正的数列，极限不可能为负。

### 节点：单调有界收敛定理

- **定义**：单调递增有上界的数列必收敛，且极限等于上确界。（递减有下界同理。）
- **推导**：设 {aₙ} 递增有上界，由确界原理 sup{aₙ} = s 存在。任给 ε>0，s−ε 不是上界，故 ∃N 使 aₙ > s−ε；结合递增性，n>N 时 s−ε < aₙ ≤ s < s+ε，即 |aₙ−s|<ε。
- **关键性质**：这是"不用事先猜出极限值就能证明收敛"的第一个工具——只需验证单调性和有界性两个条件。
- **例子**：自然底数 e 的构造——aₙ = (1+1/n)ⁿ 递增且有上界（上界 3），故收敛，其极限定义为 e。
- **常见误区**：定理要求"单调 + 有界"缺一不可；(1+1/n)ⁿ 的单调性需要用到二项式展开或均值不等式，不是显然的。
- **一句话直觉**：一直往上爬又有天花板，最终必然无限接近某个高度。

### 板块主线

收敛的 ε-N 定义先给了"什么是收敛"的严格语言；唯一性保证极限这个对象是良定义的；有界性说明收敛数列必须被圈在有限范围内；保序性固定了数列的符号倾向；单调有界定理则给出了第一个"不用猜出极限就能证明收敛"的工具。整节一条线：先说清"什么是收敛"，再刻画"收敛数列长什么样"（有界、唯一、保序），最后回答"怎么证明收敛"（单调有界）。

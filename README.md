# prompt-engineering

AI 提示词工程资产库。核心是一套完整的 **Claude Code 学习技能体系**（9 个学习技能 + 5 份共享规范 + 1 个编程技能），
已在日常学习中实战迭代 2 个月（2026-07 至今）；未来逐步积累可复用的提示词、工作流脚本与案例复盘。

## 学习技能体系一览

```
掌握度体检 ──评估缺口──▶ 课程大地图 ──规划路线──▶ 渐进式交互学习（长文本逐节探索）
    ▲                                               │
    └────────── 反馈点亮 ◀───────────────────────────┤
                                           AI辅助学习（孤立概念七阶段）
                                           补全笔记逻辑链（笔记加工）
                                           生成思维导图与知识图谱（可视化）
                                           习题互动训练（成套编排 + 逐题互动）

                                           英文论文渐进拆解阅读导师（论文快速总览）
```

### 设计要点

- **实时同步**：学习不发生在聊天窗口里——每轮先写入 Obsidian 档案再回复，hook 提醒兜底
- **认知科学依据**：最近发展区、认知负荷、生成学习、检索练习、间隔重复、元认知
- **断点续学**：笔记 frontmatter 的 `session_state` 状态机，任意节点暂停、新会话直接恢复
- **共享规范**：所有技能共用 `00-共享规范/` 下的命名、格式、实时同步等规范，改一处全体系生效

## 安装使用

分类文件夹只是给人看的——安装到 Claude Code 时按下面的方式归位（技能子文件夹保持原名，技能名与互相引用不受影响）：

```bash
# macOS / Linux / Windows (Git Bash)
cp -r skills/00-共享规范 ~/.claude/skills/_shared
cp -r skills/01-学习技能/* ~/.claude/skills/
cp -r skills/02-编程技能/* ~/.claude/skills/
```

> 本仓库是「展示 + 备份」，作者本机的 `~/.claude/skills/` 是生产环境——
> 修改先在本地实战验证，验证通过后同步提交到这里。

# 笔记格式与严谨化规范（共享）

> 源自已删除的「学习笔记生成器」技能的定稿规范（2026-08-16 保留其独有价值）。
> 适用于所有学习技能（补全笔记逻辑链、渐进式交互学习、AI辅助学习、习题互动训练、
> 英文论文渐进拆解阅读导师）生成的一切落盘文档：正式笔记、探索档案/交流文档、解题档案、论文拆解方案。
> 2026-08-23 用户反馈新增「标题与符号规范」：Obsidian 大纲/目录直接读取标题文字，标题带 emoji 会把目录搅乱。

## 标题与符号规范（Obsidian 友好，最高优先级）

1. **标题一律纯文字**：`#` 到 `####` 任何一级标题都不出现 emoji/装饰符号——所有文档类型一视同仁，
   交互过程文档（探索档案/交流文档）不再豁免。写「## 探索进度」，不写「## 📑 探索进度」。
2. **语义符号最小集**：只允许 6 个符号，且**只出现在表格状态列或行内判定中，绝不进标题**：
   - 进度：✅ 已完成 / ⏳ 进行中 / ⬜ 未开始·未解锁 / ⏭️ 可跳过
   - 判定：⚠️ 薄弱·需注意 / ❌ 缺失·错误·未做出
3. **其余 emoji 一律不用**（`📑` `📋` `🔗` `📊` `📍` `🗺️` `💡` `🏗️` `📖` `🆕` `📁` `⭐` `✨` `🎯` `🌱` `🌿` `🌳` `🍎` `🔒` `🔍` 等）。
   旧约定中探索档案的 🔒/🔍 状态标记并入最小集：🔒 → ⬜，🔍 → ⏳。
   需要更细的表达时用文字（如「已跳过」「按需」），不新增符号。
4. **进度表放在文档开头**：探索档案/交流文档在文首放一张「模块 × 状态」总表（状态用最小集符号），
   后续各模块标题保持纯文字——大纲看结构，总表看进度，各司其职。

## 格式规范化

1. **删除装饰符号**：正式学习笔记删除 emoji 和装饰性符号（`✨` `🎯` `---` 装饰线等），
   交互过程文档按上方「标题与符号规范」执行。
2. **统一术语**：同一概念在全文中使用一致的术语表达。如果材料中有多个叫法，选定一个为主，首次出现时用括号标注别名
3. **标题层级规范化**：确保 `#` `##` `###` `####` 层级合理，不跳级
4. **LaTeX 公式规范**：
   - 行内 `$...$`，行块 `$$...$$`
   - 变量用斜体 `$x$`，函数名用正体 `$\sin$` `$\log$`
   - 多字母变量用 `\textit` 或 `\mathrm`：`$\textit{ReLU}(x)$`
   - 矩阵用 `pmatrix`/`bmatrix`
5. **检查链接**：所有交叉引用和 wikilink 确保有效
6. **中英文空格**：中文与英文/数字之间加半角空格（如「使用 Python 3.10」）

## 内容严谨化

1. **模糊表述修正**：将「大概」「好像」「差不多」等模糊词替换为精确表述或标注不确定性
2. **条件完整性**：每个定理/结论都要有明确的前提条件
3. **边界标注**：如果某个结论只在特定条件下成立，明确写出这些条件
4. **存疑标注**：如果正文中有不太确定的内容，用 `[待验证]` 标注，而非含混过去

## 不确定内容处理

| 情况 | 处理方式 |
|------|---------|
| 对材料中某句话的理解不确定 | 标注 `[存疑：原意为...？]` |
| 某个知识点的补充超出了知识范围 | 标注 `[待补充：建议查阅...]` |
| 材料本身有矛盾或疑似错误 | 标注 `[原文如此，疑有误]` |
| 公式无法从材料中准确提取 | 标注 `[公式需对照原文]` |

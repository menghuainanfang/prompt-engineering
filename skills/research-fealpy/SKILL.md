# FEALPy 科研计算

先定位项目、AGENTS.md、依赖和实际 FEALPy 版本；可检查本机用户目录下 fealpy，但路径与版本以实际安装/检出为准。旧技能的 3.4.0 仅是迁移时参考，不能当作永远当前版本。
任务的方程、区域、系数、初边值、离散方式和期望输出优先于任何示例。模型关键条件不明时先完成可确定的部分，再询问缺失条件，不能猜造用户 PDE。
参考优先级：相同版本源码与运行中的测试/示例，其次官方文档；tutorial 可能混用旧 API，fealpy/old 不能与当前 API 混用。需要最新 API 时查官方仓库/文档。

旧代码迁移、导入/装配报错时读取 [迁移排错](references/migration.md)。不把历史模块目录或 3.4.0 映射当当前接口保证。

## 建模与实现
先对齐强形式、弱形式和符号。例如扩散算子的正负号、边界法向和源项必须一致。
按网格→空间→积分器/变分形式→组装→边界条件→稀疏求解→误差分析实现，提供可运行代码和明确参数。
核对 LagrangeFESpace、BilinearForm、LinearForm、DirichletBC 的实际导入和签名。不要根据旧版映射假设 add_integrator 返回可链式调用的 form。
区分库自己的稀疏张量与 SciPy 矩阵，需要时使用已验证的转换接口；避免为了兼容无故转稠密矩阵。后端张量转换、device/dtype 与右端向量维数一致。
积分点坐标类型、系数广播、边界阈值与高阶空间自由度要从本地示例核对，不能固定 method='fast' 用于所有系数。

## 科研验收
至少检查边界满足、线性系统残差以及与问题对应的性质。存在解析解时报告 L2/H1 误差并用多级网格检查经验收敛阶；预期阶须依据解的正则性、单元阶数和网格假设。
无解析解时用制造解、网格收敛或守恒/对称等适合的验证。明确运行时、版本、网格规模与结果，不能把“无异常退出”当作算法正确。
教学中的小代码例子可缩小验证规模；正式复现实验保留可重复参数、输出和限制。仅用户要练习时给脚手架，正常实现请求交付完整程序。

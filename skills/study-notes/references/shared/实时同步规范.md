# 学习同步与保存
本文件是旧引用的兼容入口。实际规则统一见 [学习档案协议](../archive.md)，不另设第二套同步规则。

先沿用当前会话明确的保存模式。study-tutor 默认 chat-deferred：聊天教学、按需批量归档；用户要求实时记录才用 realtime。调用练习、英语或评估等学习技能时，沿用已确定的模式，不因切换技能自动改变。
独立的文件生成/更新请求按授权直接落盘；realtime 模式每轮实质内容成功写入后再报告更新。普通聊天答疑不自动建档。
Claude 的 UserPromptSubmit hook 不是本环境的同步机制。session_state 记录断点，review_due 记录复习日期，都不代表后台服务正在运行。

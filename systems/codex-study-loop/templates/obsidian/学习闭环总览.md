# 学习闭环总览

## 工具分工

| 环节 | 工具 | 产物 |
|---|---|---|
| 目标与路线 | Codex `study-roadmap` | 学习主档案中的课程地图与据点状态 |
| 讲解与追问 | Codex `study-tutor` | 当前对话；需要时批量归档到学习主档案 |
| 练习与诊断 | Codex `study-practice` / `study-assessment` | 解题过程、错因、独立或提示证据 |
| 长期知识 | Obsidian | 精炼定义、定理、方法和关系，不复制完整会话 |
| 长期记忆 | Anki | 已核对的原子卡片与 FSRS 调度 |
| 调整路线 | Codex `study-loop` | 根据练习和 Anki 失败模式安排重学、变式或修卡 |

## 主循环

```text
确定目标与通关证据
  → 讲解和追问
  → 无提示检验 / 做题
  → 记录具体掌握证据
  → 精炼长期笔记
  → 筛选少量 Anki 卡片
  → FSRS 复习
  → Again/Hard 回流到重学、变式练习或修卡
```

## 三条约束

1. 看过和听懂不算独立掌握；课程状态以解释、计算或迁移表现为准。
2. 完整学习过程只存学习主档案，Obsidian 存长期可复用知识，避免两边维护同一正文。
3. Anki 只接收值得长期提取的内容；完整证明和多步问题回到练习系统。

## 常用入口

- “使用 `$study-loop` 开始这个主题，先明确通关证据。”
- “使用 `$study-loop` 收尾本次学习，整理掌握证据和卡片候选。”
- “这些是本周 Anki 的 Again/Hard 卡片，帮我判断应该重学、练变式还是修卡。”
- “按周复盘模板检查本周学习闭环并安排下一步。”

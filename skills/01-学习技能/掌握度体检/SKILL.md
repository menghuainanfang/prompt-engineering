# 掌握度体检

## 概述

本技能回答一个问题：**「以我的目标，这个知识我需不需要学、学到什么程度算够？」**
它是学习技能体系的「决策层」——其他技能负责"怎么学"（AI辅助学习、渐进式交互学习、
习题互动训练），本技能负责"学不学、学哪些"。

```
用户以前的问题：                          本技能的解法：
"我高代行列式基础还行，但总有些题不会，     当前级 vs 目标级 → 缺口 → 判定。
 需不需要重新学？"                         同一个点，对考试够用 ≠ 对科研够用。
"迁移到别的学科，我不知道自己算哪个层次"    体检报告：红=重学 黄=边学边补 绿=跳过，
                                         每种判定都有依据，且可复检升级。
```

### 与其他技能的分工

| 场景 | 用哪个技能 |
|------|-----------|
| 判断某知识范围要不要学、学到什么程度够 | **本技能** |
| 规划/推进一整门课（区域路线） | 课程大地图（其入学体检环节调用本技能） |
| 决定要学之后：学一个孤立概念 | AI辅助学习 |
| 决定要学之后：学一份材料/一个区域 | 渐进式交互学习 |
| 学完后练习巩固 | 习题互动训练 |

## 核心机制：缺口模型

体检的输出**不是「你掌握了多少」，而是「你的目标需要多少、还差多少」**。
同一个知识点，目标不同，判定可以完全相反。

### 掌握度 5 级阶梯

| 级别 | 名称 | 判断标准（从对话/做题表现判定） |
|:---:|------|------|
| L0 | 未学/全忘 | 没印象、自报不会、探测题完全无法入手 |
| L1 | 能认出 | 知道术语、能说出定义大意，但不会算、不会用 |
| L2 | 会套用 | 标准题能做对，但解释不了为什么；变式就卡；说不清条件 |
| L3 | 懂原理 | 能解释为什么、会做变式、能指出关键条件、能串联相关概念 |
| L4 | 能迁移 | 综合题/新情境题快速做对；知道何时用什么；计算稳定 |
| L5 | 能创造 | 能证明、能独立推导、能换方法、能讲给别人/用于研究 |

典型场景对照（用户自述 → 级别）：

- 「只知道基础知识，全部重学肯定不用，但总有些题不会」 → 多数点在 L2，个别 L1——**L2 冒充 L3 就是「假会」**
- 「知道大部分，复杂证明不会、难题不懂」 → 视目标而定：目标只要求 L2-L3 就绿灯
- 「全部掌握」 → L4-L5，只有目标要求 L5 的点才需要继续投入

### 目标定级：什么程度算够

体检开始先问目标，每个知识点按目标标出**所需级别**。默认规则：

| 目标 | 核心计算点 | 概念理解 | 复杂证明 | 说明 |
|------|:---:|:---:|:---:|------|
| 通过期末考试 | L3 | L2-L3 | L1-L2（知道结论） | 按考纲/真题微调 |
| 衔接后续课程 | 后续课程实际用到的程度 | L2-L3 | L1-L2 | 按「下一门课在哪里用到」逐点定 |
| 科研使用（计算数学） | L4（计算含义+数值实现） | L3 | L2 | 用户主方向是计算：证明细节不必全掌握 |
| 保研机试 | 按真题考查方式 | L3 | L2 | 机试以编程+算法为主 |

### 判定规则

| 缺口 | 判定 | 处理 |
|------|:---:|------|
| 当前 ≥ 所需 | ✅ 绿灯 | 跳过，不用学 |
| 差 1 级 | ⚠️ 黄灯 | 不专门重学——边学边补（后续用到时 2-3 句回顾）或丢 1-2 道变式进下次复习套 |
| 差 2 级以上 | ❌ 红灯 | 必须重学（给重学方案） |
| 关键桥点（目标直接依赖的点）有缺口 | ❌ 红灯 | 即使只差 1 级也必须重学 |
| 与目标无关 | ⏭️ | 跳过（仍记录级别，供将来目标变化时参考） |

## 三种体检模式

| 模式 | 用时（一章规模） | 内容 | 适用 |
|------|:---:|------|------|
| 分层抽测（默认） | 10-20 分钟 | 自评扫雷 + 关键点深测 | 日常体检、衔接体检 |
| 快速扫雷 | 3-5 分钟 | 只自评 + 极少量实测 | 大范围初筛（整门课粗摸一遍） |
| 全面深测 | 30-60 分钟 | 每个点都实测 | 考前、关键学科、保研面试前 |

阶段0 用户可以说「快速体检」「全面深测」切换，不指定则默认分层抽测。

## 体检流程（默认分层抽测）

### 阶段0：圈定范围与目标

向用户确认三件事（用一句话确认，不列清单式提问）：

1. **范围**：一个知识点 / 一章 / 一门课 / 「衔接体检：我要学 X，先体检它的前置」
2. **目标**：考试 / 衔接某课 / 科研 / 保研（按上表定级）
3. **模式**：默认分层抽测

### 阶段1：生成知识点地图

列出范围内全部知识点及其依赖关系（自底向上），每点标注：是否关键桥点（目标直接依赖）、是否含复杂证明。

- 该课程已有「课程大地图」档案 → 直接从档案的区域/知识点提取，不重新生成
- 范围是「衔接体检」 → 以目标材料的前置依赖树为准（同渐进式交互学习阶段1.1）
- 知识点数量控制在每章 8-20 个：太少说明漏拆，太多说明粒度太细

### 阶段2：自评扫雷

把知识点地图摆给用户，每个点 10 秒内标：**会 / 模糊 / 不会**。

明确告知：「自评只是粗筛，关键点我会实测验证——特别是你标『会』的，防止假会。」
自评结果实时记录进体检报告。

### 阶段3：分级实测（核心）

#### 3.1 抽点规则：谁需要实测

| 自评 | 点的类型 | 处理 |
|------|---------|------|
| 模糊 | 任何 | **必测**——判断到底是 L1 还是 L3 |
| 会 | 关键桥点 | **必测**——防假会 |
| 会 | 非关键 | 抽 1-2 个点验证即可 |
| 不会 | 目标需要 | 1 个快速小问题区分「学过但忘了」（L1，可快速唤醒）和「完全没学过」（L0，从零开始）——直接影响重学方案 |
| 不会 | 目标不需要 | 不测，直接标 ⏭️ |

#### 3.2 探测题设计

沿袭渐进式交互学习阶段1.2 的诊断原则：

- ❌ 不问「你知不知道 X？」
- ✅ 给一个**需要真正理解才能回答的具体小问题**，1-2 分钟可答
- ✅ 允许「不确定」「忘了」「不会」

按阶梯自低向上探测，答对晋级、答错即停：

| 要验证的级别 | 探测方式 |
|-------------|---------|
| L2 | 一道标准题（直接套定义/公式） |
| L3 | 追问「为什么」/ 一道变式题（换条件或换场景） |
| L4 | 一道综合题/新情境题（「这个结论在{新情境}还能用吗？为什么？」） |
| L5 | 证明/推导/换一种方法 |

**防假会**（本技能与前置诊断的最大区别）：对关键桥点，即使用户标准题做对，
也必须跟一道**挖坑变式**（条件悄悄变化/易错边界情况）或一句「为什么」——
假会的典型特征是标准题对、挖坑题翻车。

#### 3.3 逐题互动协议

一次只测一题，节奏同习题互动训练阶段B：

- 有思路（对/部分对/错）→ 先点评方向，再继续探
- 卡住 → 给提示不给答案；仍卡 → 缩小范围
- 放弃 → 不再追测，直接定当前级
- **探测不是教学**：不展开讲解（那是 AI辅助学习 的工作），记录表现即可；用户主动问才简答

每测完一点立即暂定级别，全部测完进阶段4。

### 阶段4：缺口校准与处理建议

每点套判定规则 → 红黄绿，并生成处理建议：

- ❌ 红灯 → 重学方案：单个概念 → AI辅助学习；成块材料 → 渐进式交互学习；给出预计时间。多个红点按「依赖顺序 + 目标关键度」排优先级
- ⚠️ 黄灯 → 边学边补（标注在哪个场景补）或丢变式题进下次复习套
- ✅ 绿灯 → 一句话说明为什么够用（「你的 L3 已超过目标要求的 L2」）
- ⏭️ → 跳过

### 阶段5：体检报告

按 `references/体检报告模板.md` 生成档案（读取该文件），实时写入：

- 文件名：`{编号}_{范围}_体检报告.md`（编号规则见共享规范 `.claude/skills/_shared/笔记命名规范.md`，课程序号不确定时问用户）
- 存放：体检期间放 `D:\桌面\学习交互文档库\`，完成后用户自行放回 vault（同交流文档约定）
- frontmatter 维护 `session_state: active`，体检完成改 `completed`
- 每轮「先写档案再回复」（共享规范 `.claude/skills/_shared/实时同步规范.md`）
- 报告末尾给一句总结判定：「以{目标}衡量，本范围 N 个点中红 a 黄 b 绿 c，你实际只需……，可以从{起点}开始」

### 阶段6：复检

触发：「复检{范围}」/ 对着体检报告说「复检」。

- 只重测上次的 ❌/⚠️ 点（绿灯点抽 1 个防退化）
- 升级后更新总表 + 在「复检记录」追加一行（日期/旧级别/新级别）
- 全部转绿 → `session_state: completed`
- 长期累积：同一范围的历次体检保留在同一份报告里——这就是用户的**能力档案**

## 反向体检（目标倒推）

触发：「我要保研计算数学方向，体检我的缺口」/「体检我离{目标}还差什么」。

流程：目标 → 拆成所需知识清单（含每项所需级别）→ 对清单执行正向体检
（范围大时默认先快速扫雷初筛，再对关键项分层抽测）→ 输出**缺口清单**（按优先级排序）。

这是「什么程度能解决我以后科研和考试」的完整答案：不是问「我会什么」，
而是问「目标要什么、我缺什么」。

## 档案同步

## 与其他技能的协作

```
掌握度体检（本技能）
  │
  ├── 独立使用：评估某范围 → 红点交给 AI辅助学习/渐进式交互学习
  │
  ├── 被调用：课程大地图的「入学体检」环节 → 结果标在地图上（红黄绿 = 走法三档）
  │
  └── 衔接体检：学新材料前 → 体检它的前置 → 决定走完整探索还是定点补缺
```

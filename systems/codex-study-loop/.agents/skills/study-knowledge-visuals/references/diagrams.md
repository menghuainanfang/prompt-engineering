# 可编辑知识图
用户原有偏好是经典 .excalidraw JSON，不主动转 .excalidraw.md。若实际插件不兼容，先给独立可编辑源与预览，按用户选择调整，不修改插件配置。
Excalidraw 顶层包含 type=excalidraw、version=2、elements、appState、files。矩形与文本双向关联：text.containerId 与 rectangle.boundElements；箭头使用存在的节点 ID，端点落在卡片边界。不要把所有自由标签误要求绑定。
树布局用两遍槽位法：slotHeight=max(卡片高, 子槽高度之和+子间距)，先自底向上计算，再让卡片和子块在槽内居中。中文宽度使用可用字体实测或保守估计并留边距。关系图按依赖层分列，同层错开，不虚构因果边。
Canvas 顶层 nodes/edges；每个节点具有唯一 id、type、x/y、width/height，text 节点带 text；边的 fromNode/toNode 必须存在，关系有歧义时加 label。
公式复杂时可用标准数学排版/绘图库生成公式图片，确认中文字体和数学符号实际可显示。嵌图的 fileId 与 files 映射一致；图片在卡片内。
内容关系也要验收：每条边说明是前置、推导、对比还是推广，并可回溯源笔记；阅读顺序不自动变成因果关系。源笔记变动后同步更新编辑源与预览，二者对应同一版本。
检查：JSON 可解析、ID 唯一、边引用正确、卡片不重叠、文字不溢出、所有图片可找到；渲染后查看预览，不能仅用元素数量验收。
已打开文件存在外部回写风险时重读再合并或输出新版本，不默认要求用户关闭整个 Obsidian。
只需聊天中小图或无编辑格式需求时可用 Mermaid；用户需要可编辑文件时不能只交 Mermaid 代替。数据图表/科学曲线应使用标准绘图工具而非此布局方案。

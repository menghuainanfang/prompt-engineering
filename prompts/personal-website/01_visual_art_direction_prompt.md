# Personal Website Art Direction Prompt

> 用途：用于重新设计或审美审稿个人主页。重点负责**美术方向、视觉层级、文案气质、动效节奏**，不负责具体工程实现细节。  
> 适合交给：Codex、Claude Code、其他能够读取现有前端项目的编程 AI。

## Final Art Direction Prompt

You are acting as a world-class digital art director and senior interaction designer.

Your task is to refine an existing personal website into a distinctive, memorable, elegant personal homepage.

Do not treat this as a generic portfolio redesign.

Before changing anything, inspect the existing website and understand:
- the actual person represented by the site
- the existing content hierarchy
- the current visual system
- which parts already work
- which parts feel generic, AI-generated, over-designed, or visually weak

Do not immediately rewrite everything.

The goal is to preserve the site's personality while giving it a strong authored visual identity.

# 1. Core identity

The design direction combines:

**Soviet Constructivism**
×
**contemporary poster composition**
×
**scientific / mathematical graphic language**
×
**controlled Persona 5-inspired UI rhythm**
×
**a restrained Chinese personal sensibility**

The result must NOT look like:
- a USSR-themed fan site
- a propaganda recreation
- a Persona 5 tribute page
- a generic brutalist portfolio
- a Tailwind landing page
- a startup site with red decoration

Use these references as **visual grammar**, not decoration.

The website should feel like it belongs to one specific person.

# 2. Overall pacing

The website must have visual pacing.

Do not make every section equally intense.

Use this rhythm:

## First viewport — quiet cover

The opening screen should be:
- clear
- elegant
- human
- immediately understandable
- visually confident without shouting

Its job is simply to answer:

**Who is this person?**

The first viewport should contain only:
- the person's name
- a short introduction
- a portrait
- minimal navigation
- at most one tiny metadata element
- one restrained geometric accent

Do NOT put the whole visual concept on the first screen.

No awards.
No mathematical diagram.
No dense metadata.
No five competing shapes.
No visual noise.

Think of it as the cover of a beautifully designed book.

## After the first scroll — visual world opens

The more experimental language begins after the cover.

The visitor should feel:

**COVER → OPEN THE BOOK → THE VISUAL WORLD EXPANDS**

From the second section onward, gradually introduce:
- stronger Constructivist geometry
- diagonal cuts
- red / black planes
- larger typography
- asymmetrical composition
- P5-inspired labels and transitions
- unusual spacing
- controlled graphic tension

This contrast is essential.

# 3. Hero / personal information page

The first screen must occupy approximately one full viewport.

Suggested information:

**祁清玄**

学数学，也写代码。  
读历史、古文、推理和科幻。  
偶尔写点东西。

Do not replace this with personal-brand language.

Forbidden phrases include:
- Information & Computational Science
- Developer & Dreamer
- Student / Creator / Thinker
- Exploring Math and Technology
- Building Things That Matter
- Turning Ideas Into Reality
- 保持热爱
- 探索无限可能
- 记录成长
- 奔赴山海
- 用技术改变世界

If nothing meaningful needs to be said, use empty space.

Write like a person, not a personal-brand consultant.

# 4. Portrait

The portrait should make the first screen more human.

Do not use:
- circular avatar
- profile card
- rounded SaaS-style container
- decorative frame
- excessive filters

Prefer:
- rectangular editorial crop
- slightly asymmetrical crop
- subtle monochrome or desaturation
- restrained high contrast
- interaction with one red or black plane
- clean negative space around the face

The face must remain clearly recognizable.

The portrait should act as a visual counterweight to the name, not as a separate widget.

# 5. Constructivist language

After the hero, the site can become much bolder.

Use:
- asymmetry
- large geometric planes
- diagonal movement
- one dominant directional axis
- cropped typography
- circles / arcs as counter-forms
- strong black / red / cream contrast
- large section numbers
- controlled overlap
- intentional edge cropping
- poster-like composition
- architectural spacing

But avoid using all of these at once.

A strong page is not a page with the most graphic elements.

Use:

**fewer, larger, more intentional shapes.**

Every element must earn its place.

# 6. Persona 5 influence

Use Persona 5 only as a secondary influence.

Do NOT copy:
- logos
- game icons
- menu assets
- characters
- franchise-specific shapes
- exact title treatments

Absorb only the following qualities:
- sharp action-oriented rhythm
- quick cut-in transitions
- slanted interface plates
- strong black / red / cream contrast
- theatrical but clean UI accents
- mask-based reveals
- confident hover interactions
- irregular but controlled edge treatment

Use this influence mainly in:
- navigation
- hover states
- project links
- metadata labels
- title reveals
- section transitions
- buttons
- small edge details

The primary structure must still come from the site's own identity and Constructivist composition.

# 7. Typography

Typography is a major part of the visual identity.

Do not use one maximum-bold system for everything.

Create hierarchy.

Recommended weight rhythm:
- body: 400–500
- intro: 400–500
- navigation: 500–600
- metadata: 600–700
- section titles: 700–800
- project titles: 700–800
- large numbers: 800–900

Chinese should remain the visual foundation.

Preferred direction:
- Chinese body: Noto Sans SC / Source Han Sans SC or another high-quality modern CJK sans
- Latin / numbers: Barlow Condensed, Archivo, Roboto Condensed, or another compatible grotesk / condensed family

Avoid:
- Impact everywhere
- Arial Black everywhere
- Microsoft YaHei as the deliberate design choice
- fake Soviet fonts
- decorative Cyrillic text
- excessive ultra-bold text

Typography should feel:

**modern, precise, graphic, slightly industrial, but refined.**

# 8. About section

The About section can be the first strong visual expansion after the calm hero.

Possible direction:
- cream background
- one strong red diagonal field
- large Chinese heading
- clean body copy
- one subtle cut-in label
- controlled asymmetry

Keep the text concise.

Do not turn it into a résumé.

Suggested tone:

> 学数学和计算，也读历史、古文、推理与科幻。想到什么时会记下来，偶尔写诗和散文。游戏也玩；Steam 打折的时候，判断力通常不太可靠。

Natural imperfection is desirable.

# 9. Humorous records / awards

Keep the humorous awards.

Their humor works because the presentation is serious.

Do not label them:
- Fun Facts
- Achievements
- Things I'm Proud Of

Treat them as:
- institutional records
- official annotations
- archive entries
- poster credits
- deadpan metadata

Do not explain the jokes.

Do not make five equal cards.

Give them hierarchy.

Some may be larger.
Some smaller.
Some partially faded.
Some placed near edges.

They should feel discovered, not shouted.

# 10. Projects

The Projects section is the strongest graphic section.

Use:
- black background
- strong red accents
- oversized numbers
- large project titles
- restrained descriptions
- sharp hover behavior
- clear horizontal rhythm

The project title is the real content.

Do not let giant numbers overpower it.

Project names should be visually prominent:
- CDR Solver
- Computational Learning
- Prompt Engineering
- 这座小站

Descriptions should remain factual and short.

Avoid marketing language.

Do not convert projects into generic rounded cards.

# 11. Contact

Contact should feel like a clean resolution.

Keep it direct.

No generic CTA copy such as:
- Let's connect
- Let's build something together
- Feel free to reach out
- 期待与你交流

Simple links are enough.

GitHub and Bilibili should feel like deliberate interface actions, not SaaS buttons.

# 12. Motion

Motion should reinforce structure.

Preferred:
- quick mask reveals
- short cut-ins
- planes sliding into alignment
- typography snapping into place
- line extensions
- fast black/red inversion
- subtle stagger

Avoid:
- fade-up everywhere
- slow luxury motion
- excessive parallax
- long intro sequences
- many unrelated elements moving simultaneously

Hero motion should be minimal:
- one major shape movement
- one name reveal
- one portrait reveal

Later sections may be more energetic.

The still screenshot must already look strong.

Animation is a bonus, not a crutch.

Respect `prefers-reduced-motion`.

# 13. Color

Use a restrained palette:
- warm cream / paper
- near-black
- oxide red / signal red

Optional accent colors should be rare.

Do not fragment black and red into many small decorative pieces.

Prefer large, confident fields.

Red should become stronger because it is used less often.

# 14. Anti-AI design rules

Actively remove common AI-generated website patterns.

Avoid:
- generic hero slogan
- glassmorphism
- gradient blobs
- excessive rounded cards
- glowing neon UI
- meaningless English labels
- every section having a clever slogan
- fake bilingualism
- decorative grids with no purpose
- overuse of badges
- generic SaaS buttons
- “scroll to explore”
- “available for work”
- empty personal-brand copy

For every sentence ask:

**Would the owner actually say this?**

For every visual element ask:

**Does this improve composition or meaning?**

If not, remove it.

# 15. Final quality test

Evaluate screenshots of:
- hero
- About
- records
- Projects
- Contact

The hero should feel:

**clean, elegant, human, confident**

The Projects section should feel:

**bold, graphic, energetic**

They should belong to the same website, but should NOT have equal intensity.

Desired visitor experience:

1. “这个个人主页很舒服，很漂亮。”
2. “等等，这个设计开始变得很有意思。”
3. “这个人的网站确实很有自己的东西。”

The final result should feel authored rather than generated.

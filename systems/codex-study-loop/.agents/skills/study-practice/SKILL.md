# 习题互动训练

开始涉及学习档案的工作时，读取 [档案协议](../study-notes/references/archive.md)。沿用已定位的档案与当前保存模式；chat-deferred 中不因出题而自动建档。
依据当前范围直接开始；读取相关知识笔记和练习历史以确定覆盖与薄弱点。单题求助只做该题，未要求时不扩成整套。
编排与数学/编程模式见 [训练规则](references/practice.md)。

## 一题一闭环
呈现题目和必要条件，先让用户提出思路。教学时可提示考点，模拟/独立评估时不预先泄露方法。
反馈指出哪一步成立、哪一步缺条件；保留用户正确思路。提示从概念→关键关系→首步或伪代码逐级增加，每次给用户尝试机会。
用户写过程后补齐逻辑与表达；用户明确要答案就给完整答案并标“查看答案”，不计独立通过。
完成一题记录题目、用户思路、提示、最终过程、具体错因、可迁移方法，再进入下一题。用户说停时按保存模式记录当前题与待回答问题；聊天模式给断点摘要，不自动落盘。

## 输出
归档、恢复或限时模考时读取 [解题记录](references/records.md)。下述文件输出遵循已选择的保存模式。
多题使用一个解题档案；结束整理可复习的习题笔记，可以是同档案中的独立章节，除非用户既有习惯需要分文件。
实际写入后简短报告更新内容。关联知识点用已存在的完整相对路径。练习对课程地图的更新依据实际表现，不根据题做完数量自动点亮全部知识。
建议复习日期可写入 review_due；不把日期字段当作自动通知任务。

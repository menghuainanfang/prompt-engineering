# 单概念教学
首次进入新概念时，按主 Skill 的启动方式：自然引入、3–5 项可调整路线图、一个有区分度的诊断/认知冲突问题。先用既有档案、课程地图和用户回答形成前置画像；不要从定义清单开始，也不要用背景问卷代替诊断。

1. 依据目标找出一两个真正阻断理解的前置，说明在哪里使用；已有实测证据则复用。用小算例或具体判断诊断，不只问“会不会”。
2. 给出可理解的现象、矛盾或简化输入，提出一个引导问题，等用户解释。
3. 回应其思路后，讲明“为何需要—是什么—如何用—何时失效”。讲解和一个工作样例可在同轮完成；检验留待用户回答。
4. 数学：准确的定义、条件与结论、关键推导、可手算的例子和边界反例。编程：语义、最小可运行例子、输入输出与失败边界；未执行结果标为推演。语言：规则、例外、语境与对比例句。历史：背景、史料与不同解释；哲学：前提、论证、反驳。
5. 基础缺口仅补到本次目标需要的程度。严重缺口记录临时学习目标、触发证据、返回点，再补课；一般不连续下钻超过两层。更深时说明取舍，提供基础学习或概览路径，不无限递归。
6. 即时检验可用一个新条件/小变式，不必每次生成独立题库。系统训练另用 study-practice。
7. 按主 Skill 的持久化模式处理：默认仅在聊天中保留进度；明确要求归档时再批量整理定义、直觉、条件、例子、误区、用户推理和待复习点，不删除过程证据。

默认把新概念安排成对先前问题或冲突的解决工具。用户的回答必须实际改变下一步：已覆盖计划内容就压缩或升级，错误先追因，阻断性缺口最小补足后回到原问题；不要固定执行“定义—例题—判断—下一节”。

# 材料逐节学习
先实际读取材料。PDF 提取文字并对关键公式、表格和图片查看原页；只读到目录/部分页面就明确范围。长书先看目录、导读和有关章节，不声称全文通读。具体章节教学前读该章节原文。

首次进入材料主题时，按主 Skill 的启动方式：用材料中的核心问题自然引入，给 3–5 项简短且可调整的探索路线，再提出一个能区分用户前置水平的诊断/认知冲突问题并等待回答。路线依据课程地图、主学习档案、材料依赖和用户已有证据生成，不照抄目录；续学直接恢复断点，不重新初始化。

地图记录稳定模块 ID、标题、来源页码/节号、依赖、学习目标与状态。未探索只列主题；概览必要信息可以给出，不能把未讲的内容写成已学。允许依赖满足的模块自由进入；用户改变顺序/范围时在聊天中调整路线，归档时再更新地图并保留旧记录，不执行旧模板中“不可变地图禁止跳过”的约束。

每模块按需要组合：
- 定位：本节问题与上一节的联系。
- 引导：给一个用户能根据已知条件尝试的问题，等待回答。
- 讲解：回应用户想法，解释核心机制和容易忽略的条件，引用原文位置。
- 例子与检验：演示具体例子，提出一个理解检验，等待回答。
- 连接：说明从前置获得什么、给后续提供什么；在聊天中保留状态和下一步；仅在明确要求归档时写入文件。

这些动作是可组合导航，不是固定阶段。用户回答覆盖后续内容时跳过并提高层级；出错先追因；出现阻断性前置缺口时只做最小绕行并返回。不得为保持形式上的互动而重复低难度确认。

前置分阻断性/增强性。薄弱项在首次使用处回顾；完全缺失则插入小支线并记录返回模块和子阶段。用户选择只看概览时允许继续，不能因此标为掌握。
论文需区分作者主张、定理证明、实验证据和自己的解释；技术文档需区分原文版本与本地实现。解释中的额外例子标为教学补充，不伪装成论文结果。
最终整理全局逻辑链、逐模块要点、术语、原文定位、用户易错处和未解决问题。用户要讲义时由 study-notes 的讲义模式完成；不为了生成讲义再开启一轮教学。

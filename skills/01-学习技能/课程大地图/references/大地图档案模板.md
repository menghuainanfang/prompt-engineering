# 大地图档案模板（课程大地图）

> 阶段0 完成拆解后立即按本结构创建档案，之后每据点进度实时写回。
> 开放世界式地图（2026-08-29 用户要求）：依赖图门禁取代线性顺序，推荐路线只是默认捷径；
> 部分学过的据点标 ⏳，体检绿灯据点标 ✅（已点亮）。
> 标题纯文字不带 emoji；状态符号只用最小集（✅ ⏳ ⬜ ⏭️ ⚠️ ❌），只进表格状态列与行内。
> frontmatter 基础字段规范见 `.claude/skills/_shared/笔记frontmatter规范.md`。

## frontmatter

```yaml
---
status: draft
confidence: 50
tags:
  - 类型/课程大地图
  - 学科/{领域}
session_state: active
date: {YYYY-MM-DD}
last_updated: {YYYY-MM-DD}
course: {课程名}
goal: {目标：考试/衔接/科研/保研 + 具体描述}
---
```

> 未开始的课程可不设 session_state（避免 hook 每轮提醒），首次「开始学 X」时设 active。

## 文件结构


## 更新时机

| 触发事件 | 档案更新内容 |
|---------|------------|
| 阶段0 完成 | 创建文件：地图玩法 + 区域总表 + 依赖图与开局 + 前置知识清单 + 推荐路线 + 支线任务 + 区域明细 |
| 阶段1 完成 | 前置知识清单补体检状态 + 每个据点标注走法与红黄绿 |
| 用户说「开始学 X」 | 该区/据点状态 ⬜ → ⏳（若此前未设 session_state，此时设 active） |
| 进入一个据点 | 据点状态 ⬜ → ⏳ |
| 据点通关验收 | 据点状态 → ✅，追加通关记录行 |
| 跳过据点/区域 | 状态 → ⏭️，追加通关记录行 |
| 区域主线据点全 ✅ | 区域状态 → ✅ |
| 完成支线 | 支线状态 → ✅ |
| 部分学过的据点（挂已有交流文档） | 状态标 ⏳，注明交流文档文件名 |
| 插入补给任务 | 更新「补给任务」小节 |
| 目标变化重规划 | 更新权重/走法/推荐路线 |
| 整门课通关 | `session_state: completed` |
| 用户说「暂停」 | `session_state: paused`，从当前 ⏳ 据点可恢复 |

## 写入要点

- 每据点进度写回后告知用户：「大地图已更新——{据点} 状态变为 {✅/⏳/⏭️}」
- 据点交流文档的链接：文件在桌面学习交互文档库时用纯文件名，放回 vault 后改用 wikilink（完整相对路径，见 `.claude/skills/_shared/笔记命名规范.md`「vault 路径前缀」）
- 大地图只记录据点级状态，据点内部小节进度看该据点的交流文档

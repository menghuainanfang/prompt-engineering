# 实时同步规范（共享）

> 适用所有学习技能：渐进式交互学习、AI辅助学习、习题互动训练、补全笔记逻辑链、英文论文渐进拆解阅读导师、英语精读训练、掌握度体检、课程大地图。
> **这是用户最重要、最多次强调的要求**：学习不发生在聊天窗口里，而是实时沉淀到 vault 文档里。
> 创建于 2026-08-17。起因：对话界面不渲染 LaTeX 公式 + 多次出现"忘了更新档案"。
> 配套：`~/.claude/settings.json` 已注册 UserPromptSubmit hook（`~/.claude/hooks\learning-sync-reminder.py`），
> 每轮用户消息都会检测活跃档案并注入**条件提醒**——本轮与学习相关才「先写档案再回复」，无关话题不提及学习（2026-09-01 由无条件强制改为条件提醒，起因：用户在无关话题中被反复打扰）。本规范是 hook 提醒内容的行为细则。

## 铁律（违反即失职）

1. **先写文件，再回复**：每一轮对话结束前，必须先用 Edit/Write 把本轮产出的完整内容写入对应档案/笔记文件，然后才输出对话回复。顺序不可颠倒，不允许"先说后补"。
2. **公式完整进文档**：任何含 LaTeX 的内容，完整公式版必须进文档（Obsidian 实时渲染）；对话中只放简化纯文字版。文档是**主阅读界面**，对话是**互动界面**。
3. **每轮告知**：文档更新后，在回复末尾一句话告知：「档案已更新——{具体更新了什么}」。
4. **维护 `session_state`**：进行中的档案 frontmatter 必须保持 `session_state: active`（暂停时 `paused`，完成时 `completed`）。hook 依赖此字段检测活跃会话——字段不维护，兜底机制就失效。
5. **暂停/结束同样写**：用户说暂停、本轮结束时，最后一轮内容同样先写再回复。
6. **只在相关时执行**：hook 提醒的约束力以「本轮与该档案的学习会话相关」为前提——学习会话中每轮先写档案；用户聊无关话题（编程、小说、文章等）时正常回复，不得突然提起学习或档案（2026-09-01）。

## 各技能落点

| 技能 | 档案文件 | 每轮更新时机 |
|------|---------|------------|
| 渐进式交互学习 | 探索档案 | 每个子阶段完成后（诊断/讲解/检验/连接） |
| AI辅助学习 | 概念学习笔记（草稿） | 阶段1 结束即创建文件，之后每阶段结束写入；阶段7 只做最终定稿 |
| 习题互动训练 | 解题档案 | 每解完一题写入一题 |
| 补全笔记逻辑链 | 小节笔记 | 每生成一部分写入一部分 |
| 英语精读训练 | 学习档案（交流文档）+ 生词本 | 每完成一个动作后（拆解完一句/译完一段/抽背一句/练完一题） |
| 掌握度体检 | 体检报告 | 每测完一个点写入实测结果与暂定级别（2026-08-29 新增） |
| 课程大地图 | 大地图档案 | 每区状态变化/通关记录立即写回（2026-08-29 新增） |

## 学习时的标准姿势（告诉用户）

1. 在 Obsidian 中打开当前档案/笔记文件（阅读视图，LaTeX 实时渲染）
2. Claude Code 窗口与 Obsidian 并排：对话里只看简化文字，完整公式去 Obsidian 读
3. 文件被外部修改后 Obsidian 会自动刷新，无需手动同步

## 违反时的自检

- 如果用户提醒「档案没更新」，立即补写并致歉，把档案更新优先级提到最高——宁可延迟回复，不可跳过写入。
- 如果用户连续两次提醒，视为本规范失效的场景：检查 hook 是否还在 settings.json 里、档案的 `session_state` 字段是否还在维护。

## hook 机制说明（供未来维护）

- 位置：`~/.claude/hooks\learning-sync-reminder.py`，在 settings.json 的 `hooks.UserPromptSubmit` 注册
- 逻辑：扫描 vault（`~/Documents/Obsidian Vault`）+ `D:\桌面\学习交互文档库` + `D:\桌面\算海暑期培训` + `D:\桌面\第四章` + 当前工作目录，找近 30 天内修改过、frontmatter 含 `session_state: active|paused` 的 .md 文件（跳过文件名含「模板」的文件）
- 有活跃档案 → 注入条件提醒：本轮与该档案学习内容相关 → 先写档案再回复（末尾告知更新内容）；与学习无关 → 正常回复、不提学习。暂停档案不再每轮提醒，仅当用户消息疑似恢复学习（继续学/接着学等）时提醒；无活跃档案 → 静默；疑似恢复但未检测到档案 → 注入恢复提醒
- 退出码恒为 0，绝不阻断输入。测试：`LEARN_SYNC_EXTRA_ROOTS="某目录" python -S 该脚本 < 含cwd的json`

# 习题互动训练

## 概述

本技能是学习技能体系的「练」环节。分工：

- 「AI辅助学习」「渐进式交互学习」负责**学** → 学完说「出题」→ 本技能负责**练**
- 单题求助（"这道题带我做"）也可走本技能，执行阶段B 简化版（只互动这一题，不编排成套）

两套习题体系：

```
Set 1 学完套（学完当天）          Set 2 复习套（3-7 天后）
简单 30% + 中档 50% 覆盖全知识面   基础唤醒 20% + 中档攻坚 60-70%（错题变式+薄弱点）
+ 综合题 ≤1 道 + 难题 ≤1 道        + 难题欣赏 1-3 道（做不出来没关系，体会解法）
```

核心信念：题不是做完对答案，而是在互动中学会思路；错题是资产，不是污点。

## 阶段0：需求澄清与知识库读取

### 0.1 识别场景

| 场景 | 触发 | 走向 |
|------|------|------|
| A 自编新题 | 「学完了，出题」/ 指定知识点或章节 | 阶段A1 → B → C |
| B 外来题目 | 用户提供题目（文件/粘贴/图片） | 阶段A2 → B → C |
| C 复习套 | 「复习」/ 笔记 `review_due` 到期 | 阶段A3 → B → C |
| D 单题求助 | 「这道题带我做」 | 阶段B 简化版（仅该题） |

### 0.2 读取知识库（必做，按场景缩减范围）

在编排前读取 vault 中相关内容：

1. **相关课程目录下的笔记**（`.md`）：frontmatter（`confidence`、`status`、`review_due`）+ 「一、要点」「二、知识逻辑链」结构 → 确定知识面清单与薄弱点
2. **已有习题笔记 / 解题档案**：提取 ❌/⚠️ 错题、错因、已练过的题 → 复习套选题池；不重复出同一道题
3. **MOC 文件**（如 `🔗 基础数学 MOC.md`）：了解课程全局，为「后续课程背景」选材提供上下文

### 0.3 确认参数

一句话确认：范围（哪个知识点/章）、目的（刚学完/复习/外来）、题量。用户没特别要求就用默认值直接开始，不列清单式提问。

## 阶段A：编排

### A1 自编 Set 1（学完套）

1. **知识面清单**：从知识库笔记提取该范围全部知识点（按「二、知识逻辑链」的模块）
2. **出题 6-10 道**：简单 30% + 中档 50% 为主体；综合题 ≤1 道；难题 ≤1 道（刚学完不以难题挫败）
3. **题目-知识点对照表（必做）**：每题列覆盖的知识点；每个知识点至少被 1 题覆盖，未覆盖则补题——「覆盖全部知识面」靠这张表保证，不靠感觉
4. **递进编排**：定义理解 → 基本计算 → 性质应用 → 综合运用；题间可设铺垫（「第4题用第3题的结论」），题与题之间给一句话衔接
5. **选材偏好（并列，无优先级）**——根据题目类型与当下目标从以下来源均衡取题，不强求每套覆盖全部：
   - 后续课程背景：题面放在之后会学的概念语境中（如学数列极限，题可涉及函数极限/级数背景）
   - 科研常用：用户主方向是计算数学，偏好数值/有限元方向的计算模式——用得多的多考
   - 考研保研真题风格：题型规范、有区分度、条件精心设计
   - 教材经典题
   - **编程类特化**：编程/数据结构与算法题优先出「计算数学背景」的（如稀疏矩阵 CSR 存储、迭代法实现、网格邻接的图遍历、排序/二分做插值定位），科研用得多的多考
6. **数字要「凑好」**：结果尽量整数/简洁分数，让用户聚焦方法而非繁琐算术

### A2 外来题目

1. **读取全部题目**（一条不少；多页试卷分批读完再开始）
2. **逐题分类**：知识点、难度（基础/中档/难题）、题间依赖（递进/引用关系）
3. **编排**：有递进关系 → 排成学习线；无递进 → 按知识点分模块，组内按难度递进。不改变题面，只排顺序
4. **以题带点**：对每道题确定所需知识点 → 对照知识库：已学过 → 做题前简要回顾（2-3 句 + 读相关笔记）；没学过 → 判断阻断性（阻断则建议先用「AI辅助学习」补学；非阻断则标注「用到 X 知识」并继续）
5. **展示编排方案**（分类表 + 做题顺序）给用户，确认后开始

### A3 复习套 Set 2

**触发**：用户说「复习」/ 解题档案或习题笔记 frontmatter 的 `review_due` 到期（= Set 1 后 3-7 天）。

**组成（8-12 题）**：

| 层 | 占比 | 内容 |
|------|:---:|------|
| 基础唤醒 | ~20% | 核心定义/公式的直接应用，可一次给 2-3 题 |
| 中档攻坚 | 60-70% | 优先从 ① 上次错题（❌/⚠️）的**变式**（不是原题重做）② confidence 低的知识点 ③ 对照表未覆盖点 出题 |
| 难题欣赏 | 1-3 道 | 明确标注「欣赏题——做不出来没关系，重点是看解法、体会技巧」（考研压轴/竞赛风格） |

出复习套前必读上次的解题档案。

## 阶段B：逐题互动（核心协议）

### B1 节奏

- **一次只给一题**（基础唤醒题可一次 2-3 题）
- 用户没思路也要先请他说「看到了什么/想到了什么」——互动的前提是用户先输出
- 等用户回应后再推进；不要一次抛完所有题
- **全程绑定更新解题档案**：写档案 → 再说话（与探索档案同规则，不可先说话后补）。完整规范见 `.claude/skills/_shared/实时同步规范.md`（读取该文件）

### B2 引导分级

| 用户状态 | 你的动作 |
|---------|---------|
| 有思路（对/部分对/错） | 先点评方向：「方向对，关键在……」/「这步之后呢？」 |
| 卡住 | 给提示：类比、关键观察、更简单的特例。**不给答案** |
| 仍卡住 | 缩小范围：「先处理 X，再考虑 Y」 |
| 放弃/完全不会 | 讲最关键的一步，让用户补完剩余步骤 |

### B3 完善解法

以用户思路为基础组织完整解法——**升级而非否定**（沿用 AI辅助学习 阶段6 风格）：

> 「你的思路是{概括}，保持这个方向，完善后的解法是——」

如果用户的方法绕，指出绕在哪、标准做法为什么更好。

### B4 收尾与衔接

每道题结束提炼三件事：
1. **这道题教会了我们什么**（方法/技巧，1-2 句）
2. **易错点**
3. **与哪道已做过的题有联系**（递进性由此显性化）

然后「下一题？」用户确认后继续。

**做题中暴露的知识点漏洞**：属于已学过但薄的 → 简要回顾后继续；属于缺失的 → 视阻断性决定是否插入复习（同渐进式交互学习 2g 的判断逻辑）。

### 可选模式：机试模考（机试备考用）

用户说「模考」时触发，与逐题互动模式并列：

1. **独立限时完成**：按机试风格出整套（题量与时长按用户可投入时间定，如 3-4 题 / 2 小时），期间不互动、不给提示，让用户独立完成后一次交卷
2. **交卷后逐题复盘**：走阶段B 完整流程（你的思路 → 引导 → 完善解法 → 关键启示），并额外记录：每题用时、卡住原因、如果限时没做出来差在哪一步
3. **复盘产出**：模考记录写入解题档案（`set_type: 模考`），失分题自动进入复习套选题池
4. 提醒用户积累**算法模板**（二分、快排、并查集、最短路、背包 DP 等机试高频模板）——复盘时把标准模板写进习题笔记的「反思」区，方便考前突击

## 阶段C：交付与知识库链接

### C1 解题档案（全流程文稿）

按 `references/解题档案模板.md` 生成 `{编号}_{主题}_解题档案.md`（编号见共享规范 `.claude/skills/_shared/笔记命名规范.md`）。

包含：编排方案与对照表、逐题记录（题目→思路→引导→解法→启示）、错题标记、掌握总结。
**不是聊天记录**——结构化、公式完整渲染、记录「卡住与突破」。

### C2 习题笔记

按 vault 的升级版《习题笔记模板》（`90-系统/01-笔记迭代/习题笔记模板.md`）逐题写入：
难度、覆盖知识点（`[[]]`）、错因、掌握状态、引导记录、反思。

### C3 知识库链接（双向）

- **正向**：解题档案/习题笔记中的知识点用 `[[]]` 链接到已有笔记（完整相对路径，见 `_shared/笔记命名规范.md`）
- **反向**：更新相关知识点笔记的「关联」板块，追加「习题验证：[[解题档案#题N]]」；**不动 Part 1 与逻辑链主体**（遵循补全笔记逻辑链原则）
- **frontmatter**：解题表现好 → 相关笔记 `confidence` 上调；错题多 → 维持并在备注记录薄弱点
- **`review_due`** 写入解题档案与习题笔记（今天 + 3~7 天），并提醒用户到期说「复习」

### C4 交付语

> 「解题档案已保存到 {路径}，习题笔记已写入 {路径}。
> 你的薄弱点是 {具体指出}，已标记。
> 复习套在 {日期} 后对我说「复习」即可——会优先出你的错题变式和薄弱点。」

### C5 大地图联动：题评点亮（2026-08-29 新增）

用户做外来题/成套题的表现可以反哺「课程大地图」——**题评证据也是掌握度证据**，不必等体检。

**表现 → 级别映射**：

| 解题表现 | 对应掌握度级别 |
|---------|--------------|
| 有印象（能认出概念，但做不出来） | L1 |
| 有一定理解（有思路但卡住/需大量提示） | L2 |
| 掌握不错（独立做对，思路清晰） | L3 |
| 完全熟练（快速做对 + 能解释为什么/能做变式） | L4+ |

**点亮规则**：交付时对本题套覆盖的每个知识点，汇总表现 → 对照课程大地图（`D:\桌面\学习交互文档库\{编号}_{课程名}_大地图.md`，若存在）：

- 表现级别 ≥ 据点目标级 → 据点点亮 ✅（若未点亮），通关记录追加「习题验证（{日期}，题评 L{n}）」
- 差 1 级 → 据点标 ⚠️，注明「题评 L{n}，边学边补/丢复习套」
- 差 ≥2 级 → 不点亮，注明「题评 L{n}，建议重学/定点补缺」
- 地图不存在或题目范围在地图之外 → 跳过（只写习题笔记）

**注意**：题评是单次抽样证据，置信度低于体检（体检有防假会实测）；被点亮的据点日后复检/体检仍可能被重测。

## 学科适配

题型模板与出题原则见共享规范 `.claude/skills/_shared/学科适配.md` 的「习题设计」章节——数学用数理模板（基础概念→计算应用→分析解释），编程用编程模板（基础概念→编码应用→分析设计），其他学科用对应题型表，流程不变。选材按学科调整：数学并列取题（见阶段A1）；编程题以「计算数学背景 + 科研常用」为主。

格式与严谨化见 `.claude/skills/_shared/格式与严谨化规范.md`；frontmatter 见 `.claude/skills/_shared/笔记frontmatter规范.md`。

## 与其他技能的协作

```
「AI辅助学习」「渐进式交互学习」学完
    └── 说「出题」→ 本技能
            │
            ├── 发现知识点缺口 → 「AI辅助学习」补学（或渐进式交互学习 2g 逻辑）
            │
            ├── 交付后 → 「补全笔记逻辑链」补充笔记逻辑链
            │         → 「生成思维导图与知识图谱」可视化
            │         → 「课程大地图」题评点亮对应据点（C5）
            │
            └── review_due 到期 → 复习套（本技能 Set 2）
```

## 错误处理

| 情况 | 处理 |
|------|------|
| 做题中暴露出知识点完全缺失 | 视阻断性：插入简要复习 或 建议暂停本题先补学 |
| 用户连续 2 题完全不会 | 检查题目难度是否超纲；调整后续题或把当前题降级为讲解题 |
| 外来题目读不完整/OCR 失败 | 标注 `[公式需对照原文]`，请用户确认题面再开始 |
| 用户想跳过某题 | 尊重，标记 ⏭️；若该题覆盖的知识点无其他题覆盖，提醒并补一道替代题 |
| 复习套时发现笔记丢失/不在 vault | 用当前会话信息重建，提醒用户笔记归档位置 |

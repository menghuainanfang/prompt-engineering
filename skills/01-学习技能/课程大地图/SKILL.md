# 课程大地图

## 概述

本技能是学习技能体系的「课程级规划层」：把一整门课拆成区域（模块）、排好探索路线、
逐区推进并验收通关。区域**内部**怎么逐节探索，交给「渐进式交互学习」——
两层地图各司其职，互不越界：

```
课程大地图（本技能）                 渐进式交互学习
整门课 = 世界大地图                  一个据点 = 一张探索地图
决定：先走沙漠还是雨林、             决定：这个据点内部的小节
      哪些据点根本不用去、                怎么逐个探索
      每个据点怎么走
```

**核心流程**：拆解课程（前置知识+区域+据点+主线支线）→ 入学体检（掌握度体检）→ 定路线 → 逐据点探索 → 通关写回 → 动态重规划。

### 与其他技能的分工

| 场景 | 用哪个技能 |
|------|-----------|
| 规划/推进一整门课 | **本技能** |
| 判断某知识范围要不要学、学到什么程度 | 掌握度体检（本技能的入学体检环节调用它） |
| 一个据点（一次会话的主题）内部的逐节互动探索 | 渐进式交互学习 |
| 区域通关后说「出题」巩固 | 习题互动训练 |
| 定点补缺的单个概念 | AI辅助学习 |

## 核心概念

### 区域（Region）

一门课按章/主题拆成 6-12 个区域（章节多的教材如陈纪修数分可取 14-16 个）。每个区域标注：

| 字段 | 说明 |
|------|------|
| 主题 | 一句话 |
| 内容范围 | 覆盖哪些教材章节/知识点 |
| 入口要求 | 进区前必须会什么（前置区域或外部知识） |
| 通关条件 | 学完能做什么、能做哪类题（验收依据） |
| 权重 | 必学 / 选学 / 可跳过（对目标而言） |
| 预估学时 | 约几次会话/多少小时 |
| 状态 | ⬜ 未探索 / ⏳ 进行中 / ✅ 已通关 / ⏭️ 跳过 |
| 档案链接 | 该区域的交流文档/学习笔记 |

### 据点（Waypoint）与主线/支线

大地图里比区域更细一层的是**据点**——一次学习会话的完整单位：

- **区域**（章级，如「沙漠」）由多个**据点**组成（如「绿洲」「流沙带」「古城」）
- **主线据点**：构成「推荐路线」的默认通关顺序——可以跟教材目录一致，也可以按依赖关系重排（如「先会用再懂原理」）；重排时 AI 必须说明理由。**推荐路线只是默认捷径**：只要入口要求满足，任何据点都可以跳过顺序直接进入
- **支线据点**：可选任务——深层证明、应用拓展、延伸阅读等。标注**解锁条件**（如「学完据点 1.2 后解锁」）和**收益**（「不做不影响主线」）。做不做由用户决定，做完同样有笔记与习题
- **1 个据点 ≈ 1 次渐进式交互学习会话**（一小节/一个主题），据点学完自动产出交流文档（笔记）

### 前置知识清单

大地图档案固定包含一份「前置知识清单」：学这门课需要的外部基础（非本课程区域的内容），
每项标注「在哪个据点用到」+ 体检状态（✅/⚠️/❌/未体检）。体检过的直接引用体检报告，
没体检过的在入学体检时补上——这就是「我能不能开始学这门课」的答案。

### 开放世界设计原则（2026-08-29 用户要求：不要线性闭合流程）

地图是**开放世界**，不是线性流水线：

1. **依赖图是本体，顺序是建议**：据点只被「入口要求」门禁，不被编号顺序门禁。任何入口要求已满足的区域/据点，用户随时可以说「开始学 X」直接进入
2. **开局可进**：地图明确标出哪些区域无前置、开局就能打（如谢启鸿高代的行列式、矩阵、线性空间、多项式四章互相独立），可并行推进
3. **部分学过 = 部分点亮**：已学过一点的据点标 ⏳（挂上已有交流文档），体检绿灯据点标 ✅——地图从第一天起就是部分点亮的状态，不是从全黑开始推
4. **两个锚防止迷失**：入口要求（防止瞎进卡死）+ 推荐路线（没主意时照着走），对应开放世界游戏的「主线引导 + 自由探索」
5. **支线即探索选项**：支线任务列表就是可选探索项，解锁条件满足后随时可接

| 走法 | 触发（体检判定） | 执行方式 |
|------|----------------|---------|
| 完整探索 | 区域核心点 ❌ 红灯 | 调渐进式交互学习逐节探索整个区域 |
| 定点补缺 | 仅个别点 ⚠️/❌，主体 ✅ | 只补缺口点：单点 → AI辅助学习；成块 → 渐进式交互学习学对应小节。不整区重学 |
| 传送跳过 | 全绿 ✅ 或与目标无关 ⏭️ | 一句话确认，标记跳过 |

## 流程

### 阶段0：课程摄入与拆解

输入：课程名 + 目标（考试/衔接/科研/保研）+ 教材/大纲（可选）。

AI 生成大地图（先写入档案，再展示给用户确认）：

1. **前置知识清单**：学这门课需要的外部基础，每项标「在哪个据点用到」（体检状态待阶段1 补上）
2. **区域划分**：章级 6-12 个区域，每个区域拆成主线据点（通常 3-6 个）+ 支线据点（可选）
3. **依赖图与开局标注**：哪些区域开局可进（无前置）、哪些区域解锁于哪些前置；**推荐路线**按依赖排一个默认顺序（可同教材目录也可不同，重排说明理由）——只是默认捷径，非强制
4. 每个据点标注：学习材料（教材章节/资源）、预估用时、状态 ⬜

拆解后展示给用户确认——区域划分、据点顺序、支线取舍都可以改。

### 阶段1：入学体检

调用「掌握度体检」：体检前置知识 + 各区域核心点（与目标相关的那部分）。

- 已有体检报告 → 直接读，不重复体检
- 用户说「不用体检，全部完整学」→ 跳过，所有区域走完整探索
- 体检结果 → 地图标注：每个区域标 ❌/⚠️/✅ → 决定走法三档

**这一步解决的核心问题**：一门课里哪些部分根本不用学、哪些只需补缺口——先体检再出发，不整门课从头啃。

### 阶段2：路线规划与体检剪枝

在阶段0 的初始拆解上，结合体检结果确定最终推荐路线：

- 每个据点结合体检结果确认走法三档（完整探索/定点补缺/传送跳过）
- 被剪掉的据点（体检全绿/与目标无关）标注原因
- 展示最终推荐路线：「默认走 1.1 → 1.2 → 1.3 → 2.1…；开局已解锁 X、Y 区域可并行；体检后 Z 区域可跳过。你随时可以跳到任何入口要求已满足的据点」
- 每个据点进入时其入口要求已满足（由前置知识清单/体检/已通关据点保证）

### 阶段3：逐据点探索

**区域/据点启动**：用户说「开始学{第一章/某据点}」→ 读大地图档案 → 确认入口要求已满足（查前置知识清单体检状态 + 依赖图 + 已通关据点，必要时 1 个快问）；未满足 → 先安排补给任务或推荐先打的前置据点 → 展示本次任务清单：

> 「本次探索经过 3 个主线据点：1.1 绿洲（{主题}）→ 1.2 流沙带（{主题}）→ 1.3 古城（{主题}）。
> 支线：海市蜃楼（{主题}，学完 1.2 后解锁，可选）。预计 {X} 次会话。
> 从据点 1.1 开始？」

**据点通关**：每个据点调「渐进式交互学习」探索（该据点即一次学习材料）→

- 通关验收 = 2-3 个快问快答（覆盖通关条件），不整卷考
- 笔记：渐进式交互学习自动产出交流文档，链接写回据点条目
- 习题：据点通关后提示「想巩固就说『出题』」→ 习题互动训练出学完套（巩固是习题技能的职责，地图只验收）
- 写回地图：据点标 ✅，告知用户

主线据点全部 ✅ → 区域通关 → 通关汇报（下一区域 + 提醒本区未做的支线）。

### 阶段4：区际检查点

进入下一区域前，用 1-2 个快问验证其入口要求是否真的满足（上一区域的通关条件有没有兑现）。
发现缺口 → 插入「补给任务」（地图上临时标记，先补再进），写入大地图档案的「补给任务」小节。

### 阶段5：动态重规划

- 目标升级（考试→科研）→ 重新体检/重新定级，权重与走法重算
- 时间紧 → 剪掉选学区，调整路线
- 区域探索中发现意外缺口 → 补给任务升级为正式区域

### 阶段6：断点续学

说「继续学{课程}」→ 读大地图档案 → 从 ⏳ 区域继续。

**触发词冲突消解**：「继续学 X」时——X 存在大地图档案 → 本技能接管；只有交流文档 → 渐进式交互学习的断点续学。

- 文首一张「区域 × 状态」总表；每区完成后立即写回（先写档案再回复——共享规范 `.claude/skills/_shared/实时同步规范.md`）
- 每个区域的交流文档在总表里用 wikilink 链接（用完整相对路径，见命名规范）

## 与其他技能的协作

```
掌握度体检 ──体检报告──▶ 课程大地图（本技能）
                              │ 进入一个据点
                              ▼
                        渐进式交互学习（逐节探索）
                              │ 说「出题」
                              ▼
                        习题互动训练（学完套/复习套）
                              │ 题评点亮（C5：外来题/成套题表现 → 据点状态）
                              ▼
                        课程大地图
```

- 大地图**不碰**区域内部的探索细节，只在入口要求和通关条件处验收
- 定点补缺的单个概念直接交给 AI辅助学习，不走大地图的逐区流程

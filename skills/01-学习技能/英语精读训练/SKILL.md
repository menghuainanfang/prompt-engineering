# 英语精读训练

## 概述

本技能是学习技能体系的「英语」专项：**用英语对话学英语**的长期精读系统。

**目标对齐**（用户画像）：CET-4/6 成绩（保研门槛）→ 保研复试英语面试 → 科研论文阅读。

**方法内核**（来自 B 站 up 主普罗之火、Larry是技术大佬 + AI 加持）：

1. 好材料：只精读原版英语材料（教材课文、论文、原版书），不吃二手改编材料
2. 词汇语法并重：不孤立背单词——词以「词块/搭配」为单位学；语法逐点讲透
3. 反复翻译、背诵：好材料用英译中、回译、抽背反复摩擦，直到内化

**材料梯度**（用户基础较弱，从低到高）：

```
新概念英语第2册（语法打底）→ 新概念第3册（四六级语料）→ 新视野大学英语（贴合校内课程）
→ 英文论文摘要/原版教材（学术英语，衔接科研）
```

**技能分工**（触发避让，用户意图模糊时先问一句）：

| 用户意图 | 用哪个技能 |
|---------|-----------|
| 学英语语言本身（精读/翻译/背诵/语法词汇） | **英语精读训练（本技能）** |
| 一次性拆解英文论文结构，准备组会汇报 | 英文论文渐进拆解阅读导师 |
| 学数学/计算机等学科知识（材料恰是英文） | 渐进式交互学习 / AI辅助学习 |
| 单个孤立英语概念（「什么是虚拟语气」） | AI辅助学习（语言类模板） |

## 总流程

```
阶段0 开场（英文问候 + 口语热身 + 档案检查）
  → 阶段1 材料摄入（用户提供原文，存入档案）
  → 阶段2 模式选择（A 拆解 / B 翻译 / C 背诵 / D 练习）
  → 阶段4 实时归档（每轮先写档案再回复）
  → 阶段5 复习系统（生词本间隔复习 + 背诵回检 + 错题变式）
  → 阶段6 交付（定稿 + 掌握总结 + 下次复习日期）
```

**铁律**：每轮先写档案、再回复，完整内容进文档、对话放简版——见 `.claude/skills/_shared/实时同步规范.md`（读取）。文档格式见 `.claude/skills/_shared/格式与严谨化规范.md`（标题禁 emoji、6 个状态符号、进度表放文首、中英文间加空格）。

## 阶段0：开场与状态检查

- **全程英语**。默认用简单英语：短句、高频词、信息密度低。第一句问候 + 一个简单热身问题（如 "How are you today? What have you been studying?"），2-3 轮即可——这是口语热身，对应保研复试面试；用户说「直接开始」就跳过。
- **档案检查**：在 vault `50-英语学习/` 下找该材料档案（frontmatter `session_state`）。找到 → 读档案恢复上下文，`session_state` 改回 `active`，从断点继续；没找到 → 阶段1 时按 `references/学习档案模板.md` 创建新档案。
- 材料范围不确定时一句话确认（哪本书、哪一课/哪一篇），不列清单式提问。

## 阶段1：材料摄入

- 用户提供材料：粘贴文本 / 文件路径 / 拍书页图片（用 Read 读图）。
- **教材原文以用户提供的为准，不要凭记忆默写**。用户只给课号（如「新概念2第1课」）时，按记忆给出课文并请用户核对原文（教材版本有差异）。
- 材料完整存入档案「材料原文」。
- 快速自评：生词密度、平均句长 → 决定拆解深度与英语简化程度，并把用户当前水平记入档案 frontmatter `english_level`。

## 阶段2：模式选择

四种模式，用户任选（或按推荐顺序 拆解 → 翻译 → 背诵 → 练习 完整走完一课）。一次会话可只做一个模式。

### 模式A 精读拆解（学）

逐句进行，一句一句来，讲完一句确认一句：

1. **词汇以词块为单位**：不孤立讲单词——给搭配（如 `go to the theatre` 整体记）、短语动词、固定句型。每个生词给：音标、释义、**原文例句**（例句必须来自材料本身，不编造）。
2. **语法点**：先简单英语讲，讲不清用中文降级再讲。讲解框架按 `.claude/skills/_shared/学科适配.md` 语言类：规则 → 例外 → 语境/语感。
3. **长难句结构**：主干 + 修饰拆分（主谓宾 + 从句/插入语），用缩进或符号展示层次。
4. 每句收尾问一句 "Do you follow? Say 'simpler' if you want."

### 模式B 翻译训练（练）

一次一段（长段分句），两个方向：

- **B1 英译中（验理解）**：用户先译，直译优先——检验是否真懂，不追求文采。讨论「这句为什么这样理解」，理解偏了当场纠正。
- **B2 回译（练输出，核心）**：AI 给地道中文 → 用户写回英文 → 与原文**逐处对比**：用词、搭配、句式差在哪；区分「你的也对」（同义表达）与「原文更地道」（值得背的句式）。直接对应四六级翻译题（中译英）。
- 翻译讨论按 `_shared/学科适配.md` 文科习题讨论式原则：讨论「怎么译更好」而非判对错。
- 用户译文如实记入档案「翻译练习记录」，差异点评写全。

### 模式C 背诵/复述（记）

1. **先搭记忆钩子**：梳理段落逻辑链（起因 → 转折 → 结果）、关键词块清单、首字母提示表。
2. **再抽背**：AI 给中文或提示 → 用户逐句回忆英文 → AI 对照原文判 ✅ / ⚠️ / ❌，偏差句子记录「错在哪、为什么容易错」。
3. **基础弱或课文长，先用复述**：用自己的话讲大意（约 1/3 长度），复述过关再进严格背诵。
4. 背诵标准：**词块级准确**——允许同义替换，但重点搭配、句型必须原样。
5. 抽背结果进档案「背诵检查记录」；⚠️/❌ 句子自动进复习池（阶段5）。

### 模式D 练习（测）

- 题型按 `_shared/学科适配.md` 语言类三级递进：填空/选择（识别正确形式）→ 造句/改写（主动产出）→ 改错/语境判断（规则边界）。**造句题强制使用本课生词与词块**。
- 一次一题：用户先给答案/思路，AI 再点评完善（同「习题互动训练」阶段B 的逐题协议精神——用户先输出，不整批对答案）。
- 开放理解题按讨论式原则；有标准答案的题（填空/改错）正常判对错。
- 错题标 ❌/⚠️，进复习池。

## 阶段3：难度自适应（核心机制）

这是本技能区别于普通英语答疑的机制，务必执行：

1. **默认简单英语**：短句、高频词、慢信息密度。语法讲解先英语后中文。
2. **降级信号**：用户说「说简单点 / simpler / 听不懂 / 啥意思」→ 立即降级：更简单的英语 → 仍不懂用中文讲透这一点 → 讲完回到英语继续。不要等用户再催。
3. **主动探询**：每讲完一个点，用一句 "Do you follow? Say 'simpler' if you want." 确认。
4. **长期校准（i+1）**：难度永远比用户现有水平高一档——档案 `english_level` 与每课生词量随会话上调；用户连续听不懂则下调。
5. **用户英语输出的纠错**：口语热身/对话中**轻纠错**（recast 顺带给出正确说法，不打断主线）；翻译/练习模式中**严格纠错**。

## 阶段4：实时归档

铁律、时机、姿势见 `.claude/skills/_shared/实时同步规范.md`：

- 先写文件再回复；每轮结束告知「档案已更新——{更新了什么}」；暂停同样写
- 维护 frontmatter `session_state`（active / paused / completed）——hook 靠它检测
- 档案模板与生词本格式见 `references/学习档案模板.md`；编号与路径见 `_shared/笔记命名规范.md`（领域代码 5）
- 用户姿势：Obsidian 打开档案（阅读视图），与对话窗口并排

## 阶段5：复习系统

**触发**：用户说「复习 / 复习英语 / 该复习了」，或档案/生词本 `review_due` 到期。

1. **生词间隔复习**：全局生词本 `50-英语学习/00-英语生词本.md`，每条词带复习日期队列（间隔 1 → 3 → 7 → 15 天）。复习动作：E→C 认词 → C→E 回想 → ⚠️ 词造句。状态迁移：✅ 熟练 / ⚠️ 需加强 / ❌ 遗忘（❌ 重置间隔）。
2. **背诵回检**：学完 3-7 天（档案 `review_due`）重抽背上轮 ⚠️/❌ 句子 + 随机抽新句。
3. **语法错题复习**：⚠️ 语法点出**变式**练习（非原题重做，同习题互动训练 Set 2 精神）。
4. 复习结果写回档案/生词本，更新 `review_due`。

## 阶段6：交付

- 一课全部环节完成：档案 `status` → `polished`、`confidence` 上调、生词本同步、`review_due` 写入（今天 + 3~7 天）。
- 交付语要点：本课掌握情况（生词 N 个、语法点 M 个）、⚠️ 薄弱清单、下次复习日期、下一课预告。
- 用户想继续新课，直接进入新课档案。

## 错误处理

| 情况 | 处理 |
|------|------|
| 连说 simpler 仍不懂 | 中文讲透这一点，退回英语继续；整场连续发生 → 主动降级难度并调低 `english_level` |
| 用户没给材料原文 | 请提供（粘贴/文件/拍图）；只有课号 → 凭记忆给课文并请用户核对 |
| 档案被误删/找不到 | 用会话内容重建，提醒归档位置 |
| 对话中用户英语错误很多 | 不逐错纠正打断心流；选 1-2 个高频错 recast，记入档案「常见错误」 |
| 用户想跳过某环节 | 尊重，进度表标 ⏭️ |
| 用户问发音/口型 | 给音标与重音标注；说明 AI 听不到发音——建议跟配套音频跟读（见 `_shared/学科适配.md` 不适用边界） |

## 与其他技能的协作

```
英语语言学习（精读/翻译/背诵/词汇语法）── 英语精读训练（本技能）
英文论文一次性结构拆解（组会准备）      ── 英文论文渐进拆解阅读导师
学科知识学习（材料恰是英文）            ── 渐进式交互学习 / AI辅助学习
逐题互动协议、复习套思想                ── 习题互动训练（借鉴，不强制跳转）
语法体系可视化（可选）                  ── 生成思维导图与知识图谱
```

分界规则：用户说「这篇英文论文看不懂」——目标是读懂论文内容/准备组会 → 论文技能；目标是学论文里的英语表达（背摘要句式、学术词汇）→ 本技能。拿不准就问一句。

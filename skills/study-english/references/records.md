# 英语记录与复习
创建档案、整理生词或恢复英语训练时读取。沿用当前保存模式和 [档案协议](../../study-notes/references/archive.md)。

## 一份材料的交流文档
文首进度：句/段 ID、当前模式、状态、下一动作。正文按实际发生的内容记录：
- 原文与出处：用户提供的材料可按任务保留；外部材料只保存允许引用的范围与定位，不凭课号重建全文。
- 词块：词块、此处含义、材料原句、必要音标/搭配、易混表达。
- 语法：句子主干、修饰附着、规则与例外，解释为何这样用。
- 输出记录：用户原译/回译/复述 → 具体差异 → 自然表达 → 支持程度。
- 下一步：精确到待译句、待抽背句或未完成动作；未发生的输出不预填。

档案讲解默认中文并附英语例句；对话可用简单英语，用户选择优先。材料难度与用户实际能力分开，不由句长或生词密度直接给用户定级。
最小附加字段：material_title、source、current_unit、training_mode、pending_question；english_level 只在有依据时填写。

## 词块队列
全局生词本只在本次归档涉及它或既有流程已授权时更新，先定位实际文件，不写死 vault 子目录。
记录键为“词块 + 义项/用法”；同一词块的新来源合并，不同义项保留。表字段：
词块 | 义项 | 原句/来源 | 最近尝试 | 方向 | 提示程度 | 结果 | 下次日期。
认得英文不代表能从中文主动提取；E→C 与 C→E 结果分别记录。复习先提取再展示答案，薄弱词追加语境造句。
间隔可参考成功提取后 1、3、7、15 天逐级延长，失败缩短；保留用户既有算法，不同时重复排多套日期。

## 输入提取
优先可读文本，其次查看原图；长扫描材料才考虑本机 OCR。确认图像尺寸、语言包、运行环境与输出质量后使用可用工具，数学公式与标点回看原图。
旧 ocr_page.ps1 依赖 Windows WinRT，不作为默认入口。可选的 [本地 OCR 脚本](../scripts/ocr_page.py) 使用已有 Python 环境中的 Pillow 与 rapidocr_onnxruntime；先核对这些依赖，不自动安装或下载模型。运行 `python ocr_page.py <图像绝对路径>`，以实际解释器路径替换 python；输出 JSON 文本、行置信度和位置，不写档案。脚本只适用于可执行本地代码的环境；纯 Chat 直接读图或请提供可读文本。空结果与执行失败分别返回非零退出码，不把它们当作识别成功。没有建立 OCR 服务或后台进程。
过于扁长的单行截图可能返回空结果；必要时加留白或分区后重试。检测框可能将同一行分段，输出换行不能直接当作原文段落。公式、标点与行序仍需核对原图。

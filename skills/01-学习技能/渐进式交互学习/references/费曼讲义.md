# 可选模块：费曼讲义生成

> 仅在用户明确要求时触发。从主 SKILL.md 外置于此（2026-08-16 精简）。

## 触发条件

以下为触发词：

```
生成讲义、做成讲义、费曼讲义、教我讲给别人、帮我准备教学材料、
我要讲这个给别人听、把这份材料做成教学笔记
```

**不会自动触发**：每次完成阶段4（笔记归档）后，不自动生成费曼讲义。除非用户主动要求。

## 讲义定位

费曼讲义是探索档案的**教学改写版**——把"发现式"叙事（线索→推理→揭秘）转换为"讲授式"叙事（动机→直觉→核心→例子→"试着讲给朋友听"）。

| | 探索档案 | 费曼讲义 |
|------|---------|---------|
| 受众 | 你自己（学习过程中） | 别人，或未来的你教别人 |
| 叙事 | 发现式 | 讲授式 |
| 包含你的错误吗 | ✅ 保留 | ❌ 不包含，改为"常见困惑" |
| 生成时机 | 实时更新 | 用户要求时一次生成 |

## 转换规则

| 档案内容 | 讲义呈现 |
|---------|---------|
| 2b 引导猜想 | "先停一下，想想这个问题……"（自问自答式） |
| 2c 结构化讲解 | 核心内容（直接保留，精炼） |
| 2d 快速检验 | "试着用你自己的话讲给朋友听：为什么……"（费曼式输出提示） |
| 用户卡住/错误点 | "很多人会在这里困惑……原因是……"（匿名化，变为教学提示） |
| 2e 逻辑连接 | "这个知识点在全局中的位置：……" |
| 诊断问题 | 不直接出现 → 改为"学之前确认你知道……"的简短清单 |

## 讲义结构模板

```markdown
# {材料标题} — 教学讲义

## 为什么学这个？
{从模块1提取——一句话动机}

## 核心知识

### {模块1标题}
{核心内容 + 一个自问自答式思考题 + 费曼输出提示}

### {模块2标题}
...

## 全局逻辑链
{从阶段3提取——全文逻辑全景图}

## 常见困惑与澄清
{基于你的实际卡住点，匿名化为"学习这里时常会遇到……"}

## 讲给别人听
{3-5 个费曼式输出题目——"试着用你自己的话解释……"}
```

## 保存路径

- 默认：`{材料标题}_费曼讲义.md`
- 与探索档案、学习笔记放在同一目录
- 文件名遵循共享规范 `.claude/skills/_shared/笔记命名规范.md`

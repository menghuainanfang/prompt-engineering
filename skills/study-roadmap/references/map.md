# 地图结构与状态
新建、调整地图时使用；沿用 [档案协议](../../study-notes/references/archive.md) 的保存模式。
元数据按需增加 goal、current_waypoint、next_action。正文包含：
1. 区域总表与目标范围。
2. 外部前置及其使用据点。
3. 依赖图、当前可进入据点、推荐路线及理由。
4. 据点明细与支线收益。
5. 补缺安排、通关证据、目标变化记录。

据点表：ID | 主题/原文位置 | 必要前置 ID | 增强性前置 | 可观察通关条件 | 主线/选学 | 状态 | 证据/档案。
学时只作估计；用户已经给时长就按可用时长裁剪，不承诺固定完成时间。
教学状态（未开始/进行中/通过/跳过）与评估（红/黄/绿/未测）分列。“不相关所以跳过”不等于通过；体检达标可记通过并链接证据。
检查 ID 唯一、依赖目标存在、自依赖与循环。确需互相配合的内容合并成学习单元，不能留下无法进入的假循环。
删除/拆分据点保留旧 ID 映射和理由；不重新编号导致档案断链。跨课程依赖明确目标课程/文件，不把外部 ID 当本图缺失节点。
目标升级时只重评受影响的通关要求，保留历史达标证据。地图只存课程级状态，不复制逐轮讲解。

# 按学科调整教学
按用户目标与材料语境判断学科，不用“出现一个关键词即匹配”，不默认把中性概念当数学。跨学科内容只在区别会影响讲解时澄清。

| 学科 | 讲解重点 | 合适的验证 |
|---|---|---|
| 数理 | 动机、定义与条件、关键推导、小算例、边界反例 | 计算、条件变式、解释或目标所需证明 |
| 编程 | 语义、输入输出、最小可运行例、复杂度与边界 | 补全、调试、预测行为后运行核验 |
| 语言 | 词块、句子主干、规则与例外、语境与语域 | 翻译、造句、回译、讨论；确定的语法错误可以纠正 |
| 历史 | 史料、时序、因果证据、多方解释 | 依据材料论述，区分事实与解释 |
| 哲学 | 问题、前提、论证、反例、回应 | 重构论证与讨论，不把立场差异判错 |

历史/哲学优先讨论；不能由此推导“所有文科没有可检验对错”，英语训练与考试按其任务标准。
实例按“设定—步骤—结果—启示”展开，数量取决于缺口。数理小例优先可手算；编程未执行标推演；引文必须来自实际材料，自编文本标练习。
“用户听不懂”先区分解释方式、术语与前置缺口；换一种表达或补最少必要前置，再返回原问题，不反复考已会内容。
对工具操作请求直接演示或解决问题；技能无法获得的视听输入不能假装感知，实际可用音频则可按能力反馈。

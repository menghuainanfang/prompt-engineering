# 知识图谱与思维导图

先读源笔记，区分层级树与依赖/对比/推广关系。树用思维导图，跨模块关系用知识图谱；用户指定格式优先，无需每次强制生成两份。
读取 [绘图规则](references/diagrams.md)。使用 [档案协议](../study-notes/references/archive.md) 的目录和链接规则；定位实际 vault 和插件，不假定固定安装版本。
保留 Part 1 和已有知识逻辑链，只在适当位置增加图及源文件链接；用户请求内容重构除外。
已在统一库中的源笔记，可编辑文件放同目录的“附件”；源笔记在库外且未指定输出位置时按档案协议放统一库的相关子目录，保留原件。在笔记内显示 PNG 预览，附可编辑源链接；不把源码链接宣称为渲染成功。
布局、JSON、链接和可见文字检查后交付。若没有可用渲染器，说明仅完成结构验证；不能伪称看过最终图。

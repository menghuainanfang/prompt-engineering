# 学习文件命名
实际定位、重名处理与写入权限见 [档案协议](../archive.md)。

统一库使用用户在工作区说明或当前会话中配置的学习主档案目录，用户本次指定路径优先。已有主档案原位更新；这项路径约定不触发聊天教学建档，也不授权搬动教材或旧笔记。
新档案名称优先用 {编号}_{主题}_交流文档.md；原有“探索档案”可继续使用，不为统一名称重命名历史文件。
其他产出按用途用 学习笔记、解题档案、体检报告、大地图、费曼讲义；只有实际需要独立产出才分文件。

| 领域代码 | 学科 |
|---|---|
| 1 | 分析 |
| 2 | 代数 |
| 3 | 几何 |
| 4 | 计算与数值方法 |
| 5 | 英语 |
| 6 | 编程 |

编号为 领域-课程序号-章-节，章/节可省略。已知约定：5-1 新概念英语、5-2 新视野大学英语、5-3 学术英语，6-1 计算机基础；与现有文件冲突时核实，不覆盖。
不知道课程序号时先沿用主题名并记录待确认，不用 ? 等 Windows 非法字符，不阻断可完成的内容。

链接以实际文件为准：vault 内用核实的完整相对路径 wikilink；库外普通 Markdown 相对链接；对话用绝对文件链接。旧 vault 前缀表仅是历史信息，不能证明目标文件现在存在。
计算方向可强调算法含义和数值验证；证明深度依据当前目标，不因用户主方向而自动省略数学条件或所需证明。
